## 6. Layer A: text-engine commands

Commands `0x00`–`0x0A`. These are the eleven entries of the `PutText` jump table
at <AddrRef sym="putTextJumpTable" label="0x003A3540" />. All of them operate on
the current `_MES_DATA` block; the offsets in the last column are fields of that
structure. Everything in this section is <Tag kind="confirmed" /> from the
jump-table handlers.

### 6.1 The 09 save and restore mask

Each bit selects one field of `_MES_DATA` to push or pop. This is a
general-purpose style stack; ruby text ([§12](../layout/#12-ruby-and-furigana))
is simply its most visible user.

| Bit | Field | Meaning |
|---|---|---|
| `0x01` | `u32 +0x00` | Text colour |
| `0x02` | `u32 +0x04` | Shadow colour |
| `0x04` | `s16 +0x14` | Pen X |
| `0x08` | `s16 +0x16` | Pen Y |
| `0x10` | `u16 +0x10` | Glyph width |
| `0x20` | `u16 +0x12` | Glyph height |
| `0x40` | `u8 +0x0C` | Text style (cmd `05`) |
| `0x80` | `u32 +0x20` | Text speed |

Ruby annotations use mask `0x00BC` = pen position + dimensions + speed,
deliberately omitting the two colour bits so the annotation inherits the base
text's colour.

## 7. Layer B: CTalk command dispatch

Commands `0x0E` and `0x0F`.
<AddrRef sym="TextCallBackCommand" label="CTalk::TextCallBackCommand" /> turns a
record into a table index <Tag kind="confirmed" />:

```asm
00317EF4  lbu   $v1, 0($t0)          ; cmd[0]
00317EF8  bne   $v1, 0x0E, check_0F
00317F00  lbu   $v0, 1($t0)
00317F04  andi  $v0, $v0, 0xf        ; subcommand nibble
00317F08  addiu $v0, $v0, 0x10       ; 0x0E xN -> 0x10 + N
; check_0F:
00317F24  lbu   $v0, 1($t0)
00317F28  andi  $v0, $v0, 0xf
00317F2C  addiu $v0, $v0, 0x20       ; 0x0F xN -> 0x20 + N
; dispatch: index * 12 into ms_pCommandFuncTable
00317F3C  sll   $v0, $v1, 1
00317F44  addu  $v1, $v0, $v1        ; index * 3
00317F50  sll   $v1, $v1, 2          ; ... * 4  = index * 12
00317F4C  lui   $v0, 0x3b
00317F54  addiu $v0, $v0, 0x3a80     ; CTalk::ms_pCommandFuncTable
00317F5C  jal   0x149400             ; __ptmf_scall
```

Dispatch rules:

- `0x00`–`0x0D`: index is the command byte itself.
- `0x0E`: index is `0x10 + (cmd[1] & 0x0F)`.
- `0x0F`: index is `0x20 + (cmd[1] & 0x0F)`.

The runtime table
<AddrRef sym="ms_pCommandFuncTable" label="CTalk::ms_pCommandFuncTable" /> lives
in BSS, size `0x240` = 48 entries × 12 bytes (a Metrowerks pointer-to-member
function). It is populated from a
<AddrRef sym="commandTableInit" label="static initializer" /> that uses 16-byte
records shaped `{ u32 0, u32 0xFFFFFFFF, u32 callback_addr, u32 0 }`, 48 of them.
Both forms were dumped and agree. <Tag kind="confirmed" />

## 8. Callback return flags

Every callback returns a value through `this+0x1E0`. `PutText` reads it as a
bitfield — the low byte is a state, the high bits are directives. This is what
makes constructs like `_CbProper` and `_CbSentence` possible.
<Tag kind="confirmed" /> from the loop tail at `0x002D5CF8`.

| Value | Name | Effect on `PutText` |
|---|---|---|
| low byte = 0 | continue | Keep walking the stream (subject to the typewriter budget). |
| low byte = 1 | pause | Stop for this frame; refund `0x100` of typewriter budget. |
| low byte = 2 | end | Finish this text run. Clears the stream pointer. |
| `0x100` | slot_gone | Do not write the pen position back — the block is being freed. |
| `0x200` | ptr_owned | The callback already advanced the stream pointer; do not add `(payload+1)*2`. |
| `0x400` | handled | Skip the renderer's own jump-table handler for this record. |
| `0x800` | release | With state `2`: also free the sprite lists, the style block and the `_MES_DATA` itself. |
| `0xFF` | error | Triggers an assertion and aborts the run. |

Observed combinations: `_CbSentence` returns `0x802`, `_CbProper` returns
`0x200`, `_CbEnd` returns `2`, and everything else returns `0`.
